# Augera Luxury Jewelry Website

## About The Project

Augera is a fictional luxury jewelry brand created as a modern OnePager website project.

The design is inspired by elegance, mystery and the power of the black panther.  
Dark luxury colors, cinematic images and smooth animations create a premium brand feeling.

The website was designed and developed with HTML, CSS and JavaScript without using templates or frameworks.

---

## Features

- Responsive OnePager Website
- Smooth Scrolling Navigation
- Multiple Collection Pages
- Interactive Image Slider
- CSS Hover Effects & Animations
- Dark Mode with prefers-color-scheme
- CSS Grid Layout
- Embedded Images & Video
- Luxury Inspired UI Design

---

## Website Sections

- Hero Section
- Featured Collections
- Brand Story
- Signature Panther Section
- Jewelry Gallery Slider
- Contact Section
- Footer Navigation

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

---

## Design Concept

The visual concept combines:
- dark luxury aesthetics
- elegant typography
- cinematic jewelry visuals
- panther symbolism
- smooth red gradient backgrounds

The goal was to create a modern fashion/jewelry brand experience similar to luxury campaign websites.
